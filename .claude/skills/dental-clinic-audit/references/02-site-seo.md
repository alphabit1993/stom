# Сайт: конверсия + SEO

Сначала запусти `scripts/seo_audit.py <url>` — он соберёт техническую базу
(мета-теги, H1, schema, sitemap, robots, страницы услуг, юр. страницы, счётчики).
Потом пройди чек-лист руками с телефона: 70–80% трафика стоматологии — мобильный.

Оценка пункта: 0 / 1 / 2. Блок A — конверсия, блок B — SEO, блок C — право.

## A. Конверсия (что видит пациент)

| # | Пункт | Что значит «2» |
|---|---|---|
| A1 | Первый экран | За 3 сек понятно: что, где (район/метро), почему вы. Телефон кликабелен, кнопка записи |
| A2 | Оффер | Конкретика: цена «под ключ», гарантия, срок. Не «современное оборудование» |
| A3 | Посадочные по услугам | Отдельная страница на каждое направление (имплант, all-on-4/6, брекеты, элайнеры, протезирование, виниры, терапия, гигиена, детская) |
| A4 | Цены | Прайс открыт, есть «под ключ» и «от», понятно что входит. Рассрочка/вычет указаны |
| A5 | Доверие | Реальные фото врачей и клиники, опыт, специализации, кейсы «до/после» с описанием (как у ibi.clinic) |
| A6 | Отзывы | Виджеты/ссылки на Яндекс Карты и ПроДокторов с реальным рейтингом |
| A7 | Формы | 2–3 поля, квиз на сложные услуги, онлайн-запись/виджет МИС, мессенджеры |
| A8 | Снятие страхов | Боль, анестезия, гарантия, «что будет на первом приёме», «мы не спамим звонками» |
| A9 | Как добраться | Карта, фото входа, парковка, метро — критично для локального бизнеса |
| A10 | Мобильная версия | Без горизонтального скролла, кнопки нажимаются пальцем, липкая кнопка звонка |
| A11 | Скорость | Мобильная загрузка < 3 с (PageSpeed Insights mobile ≥ 50, LCP < 2,5 с) |
| A12 | Аналитика | Метрика с целями (звонок, форма, мессенджер), коллтрекинг, UTM, сквозная аналитика |

## B. SEO

### Техническое
| # | Пункт | Норма |
|---|---|---|
| B1 | HTTPS + единое зеркало | Редирект http→https и www/без www на одну версию |
| B2 | robots.txt и sitemap.xml | Есть, sitemap указан в robots, нет закрытых важных разделов |
| B3 | Индексация | В Вебмастере/по `site:` число страниц ≈ числу полезных страниц, нет мусора и дублей |
| B4 | Title/Description | Уникальные, с услугой + гео: «Имплантация зубов в Митино — цена под ключ от …» |
| B5 | H1 | Один на страницу, совпадает с интентом |
| B6 | Schema.org | `Dentist`/`MedicalClinic` + адрес, телефон, часы, рейтинг; `Physician` для врачей |
| B7 | Ошибки | Нет 404 во внутренних ссылках, битых картинок, цепочек редиректов |
| B8 | Яндекс Вебмастер | Подключён, регион присвоен, нет угроз и критичных ошибок |

### Контентное и локальное
| # | Пункт | Норма |
|---|---|---|
| B9 | Семантика по услугам | Каждая коммерческая группа запросов (Wordstat) имеет свою страницу |
| B10 | Гео-страницы | Для сети/широкого охвата: страницы под районы/метро (без дублей текста) |
| B11 | E-E-A-T | Страницы врачей: образование, сертификаты, стаж, работы; автор и проверка статей |
| B12 | Полезный контент | Ответы на вопросы пациентов (цены, боль, сроки, противопоказания) |
| B13 | NAP | Название, адрес, телефон одинаковы на сайте, картах и агрегаторах |
| B14 | Позиции | Проверить топ-10 Яндекса по 15–20 ключам «услуга + район/Москва» (Topvisor, Rush, Keys.so) |

Сравнение с конкурентами по SEO: видимость в Keys.so/Rush Analytics, число страниц
услуг, наличие цен и врачей. Если у конкурента в 3 раза больше посадочных — это
и есть разрыв.

## C. Право (риск штрафов и блокировки рекламы)

| # | Пункт |
|---|---|
| C1 | Лицензия на медицинскую деятельность (номер, дата, кем выдана, перечень работ) |
| C2 | Информация по правилам платных медуслуг (ПП РФ № 736): реквизиты, прайс, сведения о врачах (образование, квалификация), режим работы, контролирующие органы |
| C3 | Политика обработки ПДн + отдельное согласие у каждой формы (152-ФЗ) |
| C4 | Иностранные сервисы на сайте (Google Analytics, Google Fonts, reCAPTCHA, YouTube) — риск по трансграничной передаче ПДн |
| C5 | Предупреждение «Имеются противопоказания, необходима консультация специалиста» в рекламных блоках/баннерах |
| C6 | Отзывы и «до/после» — с согласиями пациентов |

Правовые пункты не оценивай как юрист: помечай риск и рекомендуй проверку.

## Типичные находки → точки роста

- Одна общая страница «Услуги» → нет посадочных → Директ дорогой, SEO не растёт.
  Шаг: посадочные под 3 приоритетных направления с ценой, врачами, кейсами, квизом.
- Нет цен → пациент уходит к конкуренту с ценами. Шаг: прайс «от» + «под ключ».
- Формы без целей в Метрике → невозможно считать CPL. Шаг: цели + коллтрекинг.
- Медленная мобильная версия → потеря 20–50% трафика до загрузки. Шаг: сжатие
  изображений, ленивая загрузка, отключение лишних скриптов.
- «Профессиональные врачи и доступные цены» → ноль отличий. Шаг: оффер с конкретикой.
