# Конкурентный анализ

## Кого брать

3–7 клиник:
- 3–5 ближайших в радиусе 1–3 км (из выдачи Яндекс Карт по «стоматология» из точки клиники);
- 1–2 сетевых игрока района (они задают цену и аукцион в Директе);
- 1 эталон рынка по упаковке (например, клиника с сильным сайтом/кейсами) — для идей,
  не для прямого сравнения.

## Что сравниваем (таблица `templates/competitors.csv`)

| Блок | Параметры |
|---|---|
| Позиционирование | Специализация, ценовой сегмент, главный оффер, УТП, гарантии |
| Цены | Консультация, имплант «под ключ» (бренд), коронка на имплант, брекеты/элайнеры, гигиена, лечение кариеса, удаление. Рассрочка, вычет |
| Карты | Позиция по 5 ключам, рейтинг, число отзывов, отзывов за 3 мес, ответы, фото, услуги с ценами, приоритетное размещение |
| Агрегаторы | Рейтинг на ПроДокторов/СберЗдоровье, число врачей, онлайн-запись |
| Сайт | Посадочные по услугам, цены, врачи, кейсы, квизы, скорость, мобильная версия |
| SEO | Видимость (Keys.so/Rush), позиции по ключам «услуга + район» |
| Реклама | Есть ли в Директе по ключевым запросам (видно в выдаче), тексты и офферы объявлений, ВК-сообщество и реклама, Клипы |
| Сервис | Тайный звонок к 2 главным конкурентам: скорость, скрипт, цена, предложение времени |

## Как делать выводы

1. **Карта цен:** где клиника дороже/дешевле рынка района на ключевых услугах.
   Дороже — нужно обоснование (бренд имплантов, гарантия, врач, «под ключ» без доплат).
2. **Разрыв по репутации:** сколько отзывов в месяц надо собирать, чтобы за 3–6 мес
   выйти на уровень лидера района.
3. **Свободная ниша:** направление/оффер/аудитория, которые конкуренты не закрывают
   (детская, лечение во сне, протезирование для 55+, вечерние/выходные часы,
   all-on-4, ДМС).
4. **Что украсть:** лучшие офферы, формулировки, форматы кейсов, квизы — адаптировать.
5. **Где не конкурировать:** если сеть демпингует на гигиене — не воевать ценой,
   а уходить в сервис и комплексные планы.

## Наблюдения по офферам в Директе (из практики пользователя)

- Заголовки с «Честные цены» / «Лучшие цены» стабильно давали низкий ДРР
  (в кейсе — ниже 10%) — гипотеза для теста у новой клиники.
- Аудитория 55+ — стартовая гипотеза для протезирования и имплантации
  (в кейсе — 73% расхода на доходных объявлениях).
- Работают выгоды через снятие боли пациента: «Лучшие цены на протезирование.
  Не выпадают, не натирают».
- Вопрос в заголовке без выгоды («Сколько стоит коронка на имплант в Митино? Узнать…»)
  отработал плохо.
- Правило: не трогать работающие кампании без алгоритма изменений; резкие просадки
  лидов часто вызваны правками лендинга или бюджета подрядчиком.
