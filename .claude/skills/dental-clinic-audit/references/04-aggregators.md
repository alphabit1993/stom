# Медагрегаторы: ПроДокторов, СберЗдоровье и другие

В Москве пациент сравнивает врачей на агрегаторах перед записью, даже если пришёл
из рекламы. Агрегатор одновременно и канал записи (платный за запись/лид), и витрина
репутации. Официальных формул рейтинга площадки не публикуют — опирайся на то, что
видно в карточке, и на практику: полнота профиля, свежесть и количество отзывов,
ответы клиники, активность врачей.

## Список площадок для проверки

| Площадка | Что проверять | Приоритет для Москвы |
|---|---|---|
| ПроДокторов | Клиника + каждый врач, рейтинг, отзывы, запись | Высокий |
| СберЗдоровье (бывш. DocDoc) | Клиника, врачи, онлайн-запись, слоты, цены | Высокий |
| НаПоправку | Клиника, врачи, отзывы | Средний |
| Zoon | Карточка, отзывы, рейтинг | Средний |
| 2ГИС, Яндекс Карты | См. `03-geo-maps.md` | Высокий |
| Отзовик, IRecommend | Негатив о клинике, «вечные» темы | Проверить |
| Рейтинги стоматологий (rating.startsmile.ru и т.п.) | Участие, позиция, заявка на включение | Низкий/репутационный |

## Чек-лист ПроДокторов (0/1/2)

| # | Пункт | Норма |
|---|---|---|
| P1 | Карточка клиники | Подтверждена, адрес/телефон/часы/фото актуальны, описание с направлениями |
| P2 | Все врачи заведены | Каждый действующий врач на площадке; уволенные — отвязаны от клиники |
| P3 | Карточки врачей | Фото, специализации, стаж, образование, курсы, услуги с ценой приёма |
| P4 | Рейтинг врачей | Нет врачей с низким рейтингом без работы над ним; видно, кто «звезда» |
| P5 | Отзывы | Количество и свежесть: новые отзывы каждый месяц по каждому ключевому врачу |
| P6 | Ответы клиники | Ответы на отзывы, особенно на негатив; корректно, без раскрытия медданных |
| P7 | Онлайн-запись | Подключена, расписание синхронизировано с МИС, слоты реальные |
| P8 | Цены | Стоимость приёма совпадает с сайтом и прайсом |
| P9 | Активность врачей | Статьи/ответы на вопросы на сервисах площадки (дают видимость) |
| P10 | Обработка заявок | Заявки подтверждаются быстро, отказы фиксируются, есть отдельный скрипт для КЦ |

| S6 | Обработка заявок | Время подтверждения, доля дошедших, причины отмен |
| S7 | Экономика | Стоимость записи/пациента vs чек первичного и конверсия в план |

## Экономика агрегаторов (обязательно посчитать)

```
CAC агрегатора = оплата за записи за месяц / число пришедших первичных
Окупаемость    = (первичные × доля, принявших план × средний план × маржа) / оплата
```
Частые ошибки: платят за записи, которые не дошли; КЦ не подтверждает запись в
кабинете → пациент не приходит; на агрегаторе стоят врачи с низкой конверсией в
план лечения — поток уходит в «консультацию без продолжения».

## Заметки для КЦ/ОП по агрегаторам

Из карты проекта (лист «Продо»): у КЦ и ОП должна быть отдельная памятка по
пациентам с ПроДокторов и СберЗдоровья. Минимум, что в ней должно быть:
- пациент уже выбрал врача по отзывам — подтверждаем выбор, а не «перепродаём»;
- быстрое подтверждение записи (до 15 мин) и напоминание за день;
- цена приёма должна совпадать с указанной на площадке — расхождение = негативный отзыв;
- после визита — просьба оставить отзыв именно на той площадке, откуда пришёл пациент.
Если у пользователя есть полный текст листа «Продо» — попроси его и сверь с этим списком.

## Типичные находки → точки роста

- Половина врачей не заведена или с пустыми карточками → потеря записей и рейтинга.
  Шаг: заполнить карточки всех врачей (фото, опыт, курсы, услуги, цены) за 2 недели.
- Лучший по конверсии врач без отзывов → поток идёт к слабым. Шаг: сбор отзывов
  по этому врачу, вывести его на агрегатор на приоритетные услуги.
- Оплата за записи без контроля прихода → переплата. Шаг: сверка заявок агрегатора
  с МИС ежемесячно, оспаривание недошедших по правилам площадки.
