# Анализ отзывов

Отзывы — это бесплатное исследование воронки клиники глазами пациента.
Задача не «посчитать звёзды», а понять, **на каком этапе пути пациента клиника
теряет людей и деньги**.

## Сбор данных

Площадки: Яндекс Карты, 2ГИС, ПроДокторов, СберЗдоровье, НаПоправку, Zoon, Google, Отзовик.
Берём отзывы за последние 12 месяцев (минимум 50, если есть), для конкурентов — по 20–30
последних. Таблица `templates/reviews.csv`:
`площадка, дата, оценка, врач, услуга, этап, тема, тональность, ответ клиники (да/нет), время ответа, цитата`.

## Метрики

| Метрика | Норма для Москвы |
|---|---|
| Средний рейтинг по площадкам | ≥ 4,8 Яндекс; ≥ 4,5 ПроДокторов (сравнить с соседями) |
| Новых отзывов в месяц (все площадки) | 10+ на клинику; у лидеров района — смотри конкурентов |
| Свежесть | Последний отзыв не старше 2 недель |
| Доля отзывов с ответом | 100% негатива, ≥ 80% всех |
| Время ответа на негатив | ≤ 24 ч |
| Доля 1–3★ | < 10% |
| Распределение по врачам | Нет «невидимых» врачей; виден лидер по каждому направлению |

## Разметка по этапам пути пациента

Каждый отзыв относим к этапу — так негатив превращается в адрес проблемы:

| Этап | Типичные темы | Чья зона |
|---|---|---|
| 1. Дозвон/запись | «не дозвониться», «не перезвонили», «грубый администратор», «спам-звонки» | КЦ/админы |
| 2. Визит и сервис | ожидание, опоздания, чистота, парковка, найти вход | Ресепшн/управляющий |
| 3. Консультация и план | «навязывают», «цена выросла», «не объяснили», «развели на КТ» | Врач/куратор, прозрачность цен |
| 4. Лечение | боль, качество, осложнения, переделки | Медицинский директор |
| 5. После лечения | гарантия, контроль, отношение к претензии | Управляющий/куратор |
| Позитив | что хвалят: врач, безболезненность, объяснение, цена, атмосфера | → в офферы и рекламу |

Позитив так же важен: фразы пациентов («объяснил всё на снимке», «совсем не больно»)
— лучшие тексты для объявлений, сайта и скриптов КЦ.

## Выводы, которые нужно сделать

1. Топ-3 темы негатива с долями → в какие этапы воронки вести исправления.
2. Топ-3 темы позитива → в оффер и УТП.
3. Врачи: кто собирает отзывы, у кого негатив, кто «невидим».
4. Сравнение с конкурентами: у кого рейтинг/скорость сбора выше и за счёт чего.
5. Есть ли признаки накрутки (у клиники или конкурентов): одинаковые тексты, всплески
   за 1–2 дня, аккаунты без истории. Накрутку не рекомендуем никогда.

## Процесс сбора отзывов (если отзывов мало)

- Просьба на выходе: администратор/куратор + QR на стойке с прямой ссылкой на площадку.
- Сообщение через 2–24 ч после визита со ссылкой (лучше на площадку, откуда пришёл пациент).
- Врач просит лично после удачного этапа лечения.
- Не стимулировать скидками за положительный отзыв (правила площадок).
- KPI: число отзывов в неделю по клинике и по врачам, отчёт раз в неделю.

## Ответы на отзывы — шаблон

Негатив: благодарим → признаём опыт пациента (без спора и медданных) → что
делаем/сделали → прямой контакт для решения. Позитив: персонально, с именем врача
и услугой (это ещё и ключевые слова для площадки).
